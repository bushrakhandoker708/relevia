# Mockups

These are static HTML design studies from November 2026, kept as I made them. [`../DESIGN_LOG.md`](../DESIGN_LOG.md) explains what each one tested and why the final design is a blend of the two directions.

To view one, open the HTML file in a browser. These files are not part of the built site. Unlike the site, they load their fonts from Google Fonts, so opening them online makes a request to Google.
